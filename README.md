# Agenda de Contactos

Aplicación de escritorio desarrollada en Python
para administrar contactos mediante archivos
de registros de tamaño fijo y acceso aleatorio.

## Tecnologías

- Python 3.14
- PySide6
- ReportLab
- JSON
- SHA-256
- ZIP

## Funcionalidades

- Administración de contactos.
- Búsqueda mediante índice primario.
- Modificación de registros con seek().
- Exportación JSON y PDF.
- Verificación de integridad.
- Respaldos comprimidos.
- Consulta de metadatos y permisos.

## Ejecución

Ejecutar el archivo main.py desde PyCharm.
